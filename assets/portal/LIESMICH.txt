===============================================================================
  PiPortal  –  Willkommen
===============================================================================

Dieser Datenträger ist nur ein WEGWEISER. Die eigentlichen Dateien liegen
auf einem geschützten Netzlaufwerk direkt auf dem PiPortal-Stick.

-------------------------------------------------------------------------------
  So greifst du auf deine Dateien zu
-------------------------------------------------------------------------------

1) Warte ~20-30 Sekunden nach dem Einstecken (der Pi bootet).

2) Öffne den Windows-Explorer und gib oben in die Adresszeile ein:

        \\10.10.0.1\PiPortal

   Alternativ per Verknüpfung: Doppelklick auf  "PiPortal-Netzlaufwerk.url"
   auf diesem Datenträger.
   Für einen echten Laufwerkbuchstaben (nur bis zum Neustart, nicht dauerhaft):
   Doppelklick auf  "Netzlaufwerk-verbinden.cmd".

3) Melde dich mit deinem SMB-Benutzer und -Passwort an.
   Tipp: den Benutzernamen als  10.10.0.1\dietpi  (bzw. PiPortal\dietpi)
   eingeben – sonst versucht Windows dein lokales PC-Konto.
   BEIM ERSTEN MAL: Passwort noch nicht gesetzt? Doppelklick auf
   "SMB-Passwort_setzen.vbs" auf diesem Datenträger – dort legst du
   Benutzer + Passwort fest (ohne Datenverlust).

-------------------------------------------------------------------------------
  Terminal-Zugang (SSH)
-------------------------------------------------------------------------------

Windows bringt SSH bereits mit - kein PuTTY nötig. Öffne PowerShell oder CMD:

        ssh dietpi@10.10.0.1

Oder Doppelklick auf  "connect-piportal.cmd"  auf diesem Datenträger.

-------------------------------------------------------------------------------
  Hinweise
-------------------------------------------------------------------------------

- Der PiPortal hat sein eigenes Internet (WLAN). Deine PC-Internetverbindung
  bleibt unberührt.
- Dieser Wegweiser-Datenträger ist schreibgeschützt (read-only). Ablegen von
  Dateien bitte über das Netzlaufwerk \\10.10.0.1\PiPortal.

-------------------------------------------------------------------------------
  Passwort fürs Netzlaufwerk vergessen?
-------------------------------------------------------------------------------

Doppelklick auf  "SMB-Passwort_vergessen.vbs"  auf diesem Datenträger.
Es öffnet eine SSH-Sitzung zum PiPortal, in der du den Zugang neu setzt.
ACHTUNG: dabei werden ALLE Dateien auf dem Netzlaufwerk gelöscht. Wer sich
per SSH anmelden kann (Benutzer dietpi), darf zurücksetzen.
